# techtime-market-data — نظام تحديث بيانات المنافسين المجاني بالكامل

هذا المستودع يشغّل نفسه تلقائيًا كل يوم عبر GitHub، يجمع أسعار المنافسين
وبيانات اهتمام Google Trends، ويحفظها بملف `data/products.json` يقدر
تطبيق TechTime Growth OS يقرأه مباشرة.

**التكلفة: صفر ريال.** كل الأدوات المستخدمة مجانية بالكامل.

## نظرة عامة على المنافسين المُضافين

| المنافس | حالة الثقة بالسيلكتور |
|---|---|
| ppowerstore | متوسطة |
| mokab | متوسطة |
| iblackstores، aletawiksa، saada، wjhtektelecome، al3bor-telecom، hope، alwan7، sync | منخفضة — تقديرية، تحتاج تعديل بعد أول تشغيل |
| amazon.sa، noon، jarir، extra | منخفضة جدًا — حماية قوية ضد الزحف، النتائج غير مضمونة بدون Playwright وإعدادات إضافية |

المتاجر المبنية على منصة **سلة (Salla)** غالبًا تتشابه ببنيتها، فلو ظبطتوا
سيلكتور واحد صح لمتجر سلة، غالبًا نفس الإعداد يشتغل لبقية متاجر سلة
بأقل تعديل.

## الخطوات — أول مرة فقط (15-20 دقيقة)

### 1) إنشاء حساب GitHub (لو ما عندكم)
اذهبوا إلى github.com → Sign up → مجاني بالكامل.

### 2) إنشاء مستودع جديد (Repository)
- اضغطوا "New repository"
- الاسم: `techtime-market-data` (أو أي اسم تحبونه)
- اختاروا **Public** (مهم — عشان تطبيق React يقدر يقرأ الملف مباشرة بدون تعقيد)
- اضغطوا "Create repository"

### 3) رفع الملفات
ارفعوا كل الملفات والمجلدات اللي بهذا الحزمة (اسحبوها وأفلتوها بصفحة GitHub
مباشرة عبر "Add file" → "Upload files"، أو استخدموا Git لو تعرفون):
```
techtime-market-data/
├── .github/workflows/daily-scrape.yml
├── scripts/scraper.py
├── scripts/requirements.txt
├── data/products.json
└── README.md
```
⚠️ مهم: تأكدوا مجلد `.github` رفع بالضبط بهذا الاسم (فيه نقطة بالأول) —
لو GitHub ما عرضه بالواجهة، ارفعوا الملف `daily-scrape.yml` وأول ما
تكتبون المسار بخانة اسم الملف اكتبوا `.github/workflows/daily-scrape.yml`
كامل والموقع يسوي المجلدات تلقائيًا.

### 4) تفعيل الصلاحيات
اذهبوا إلى: **Settings** (بالمستودع) → **Actions** → **General** →
انزلوا لـ "Workflow permissions" → اختاروا **"Read and write permissions"**
→ احفظوا. (بدون هذي الخطوة، السكربت ما يقدر يحفظ النتائج تلقائيًا).

### 5) أول تشغيل يدوي (للتأكد إنه شغال)
اذهبوا لتبويب **Actions** بالمستودع → اختاروا workflow
"تحديث بيانات المنافسين اليومي" → اضغطوا **"Run workflow"** يدويًا.
انتظروا دقيقة-دقيقتين، وشوفوا اللوق (Log) — بيوريكم أي منافس نجح
وأي منافس فشل (يحتاج تعديل selector).

### 6) بعدها — يشتغل لحاله كل يوم
ما تحتاجون تسوون شي بعد كذا. الجدولة (`cron`) بالملف تخلي GitHub
يشغّله تلقائيًا الساعة 6 صباحًا (توقيت السعودية) كل يوم.

## لو منافس ما اشتغل معه الزحف (طبيعي جدًا بالبداية)

كل موقع مبني بشكل مختلف، فـ "الـ selectors" (أماكن اسم المنتج والسعر
بالكود) تختلف من موقع لموقع. لتحديد الصح:

1. افتحوا صفحة نتائج بحث بموقع المنافس بمتصفح Chrome
2. كليك يمين على اسم المنتج → "فحص العنصر" (Inspect)
3. لاحظوا الـ `class` اللي يحيط بالعنصر (مثال: `class="product-title"`)
4. عدّلوا `scripts/scraper.py` وحطوا `.product-title` بمكان `title_selector`
5. كرروا نفس الشي للسعر

⚠️ **مواقع Salla و JS-heavy**: بعض المواقع (زي متجركم نفسه وبعض
المنافسين) تحمّل المنتجات عبر JavaScript فما تظهر لمكتبة `requests`
العادية. الحل: استبدال `requests` بمكتبة **Playwright** (مجانية
برضه، لكن أثقل شوي وتحتاج سطر إضافي بملف الـ workflow لتثبيت متصفح
داخلي). لو حبيتوا، رجعوا لي وأبني لكم نسخة الـ Playwright.

## ربط تطبيق TechTime Growth OS بالبيانات الحية

بعد أول تشغيل ناجح، رابط بياناتكم الجاهزة يكون:
```
https://raw.githubusercontent.com/USERNAME/techtime-market-data/main/data/products.json
```
(استبدلوا USERNAME باسم حسابكم بـ GitHub). أرسلوا لي هذا الرابط وأربط
موديول "قاعدة بيانات المنتجات" بالتطبيق ليقرأ منه مباشرة بدل الإدخال اليدوي.

## حدود صادقة يفضل تعرفونها

- **pytrends غير رسمية**: تحاكي المتصفح لسحب Google Trends، أحيانًا
  تتوقف مؤقتًا (Rate Limit) — طبيعي، السكربت يتجاوزها بصمت.
- **الأرقام درجة اهتمام نسبية (0-100)** مو رقم بحث شهري دقيق مثل
  Keyword Planner الحقيقي.
- **الزحف يحتاج صيانة كل فترة** — لو منافس غيّر تصميم موقعه، السكربت
  ينكسر لذاك المنافس تحديدًا (يبان بلوق الـ Actions) ويحتاج تعديل
  الـ selector بس، مو إعادة بناء كامل.
- راجعوا شروط استخدام كل موقع قبل الزحف المكثف، وخلوا فترات الانتظار
  بين الطلبات (موجودة بالسكربت افتراضيًا) عشان ما تُحظرون.
